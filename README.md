## 🧭 什么是"回国加速"?

和"翻墙出去"相反,回国加速解决的是**从海外访问中国大陆内容**的问题。
国内的视频、音乐、游戏平台普遍做了地域版权限制(IP 识别),海外 IP 会被拒绝或体验极差。回国加速器通过把你的网络请求路由回中国境内的节点,让平台"以为"你在国内,从而正常使用。

详细原理见:[什么是回国加速器](./docs/guides/什么是回国加速器.md)
